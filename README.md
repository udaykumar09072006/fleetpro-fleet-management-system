# 💍 Wedding Planner & Vendor Booking Platform

A modern, responsive wedding planning platform designed to help couples organize their special day by exploring vendors, comparing services, managing budgets, and handling bookings in one place.

🔗 **Live Demo:** [https://applet-kappa.vercel.app](https://applet-kappa.vercel.app)

## ✨ Features

- **Vendor Discovery:** Explore wedding-related services and vendors.
- **Vendor Comparison:** Compare available options to make informed decisions.
- **Booking Flow:** Multi-step booking experience for organizing reservations.
- **Budget Tracking:** Keep track of wedding expenses and planned budgets.
- **User Dashboards:** Dedicated interfaces for managing wedding-related activities.
- **Calendar Management:** Organize bookings and important dates.
- **Payment UI:** Simulated payment options for demonstrating the booking experience.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- **Modern UI:** Clean interface with intuitive navigation and styling.

## 🎯 Project Objective

The goal of this project is to simplify wedding planning by bringing vendor discovery, booking workflows, and event organization together in a single web application.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

For a Node.js project using npm:

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

> These commands assume your project uses npm and has a `dev` script in `package.json`. Adjust them if your setup is different.
